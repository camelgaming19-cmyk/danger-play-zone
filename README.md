# QB AI Menu v2.0.0 - NPC Spawning System

**100% Working Standalone Script - No Dependencies!**

A fully functional, lightweight NPC spawning and management system for FiveM servers. Works with or without QBCore!

## ✅ Features

- ✔️ **Zero Dependencies** - Works standalone, no QBCore required
- ✔️ **Easy NPC Spawning** - Spawn Guards, Cops, Civilians, Mechanics, Doctors
- ✔️ **Full Menu System** - Navigate with arrow keys, select with ENTER
- ✔️ **NPC Management** - Delete individual or all spawned NPCs
- ✔️ **Information Display** - View total spawned NPCs in real-time
- ✔️ **Chat Notifications** - Get feedback on all actions with emojis
- ✔️ **Keybind Control** - Press `T` to toggle the menu
- ✔️ **Exports Available** - Access functions from other scripts
- ✔️ **No Conflicts** - Standalone design prevents conflicts with other scripts
